# Vision Skill

1. **Input Inspection**:
   - Verify image path exists and check image file format (PNG, JPG, WEBP, etc.).
2. **Analysis Focus**:
   - Extract text from charts, flowcharts, tables, and handwritten notes.
   - For diagrams, explain components, relations, and data flow.
   - For document scans, extract structured key-value pairs or tabular layouts.
