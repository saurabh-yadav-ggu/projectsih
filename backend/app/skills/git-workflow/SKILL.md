# Git Workflow Skill

## When to Use
Use when checking repository status, inspecting diffs, creating branches, or staging changes.

## Instructions
1. Always run `git status -s` first to understand current changes.
2. Use `git diff` to review exact modifications before committing.
3. Keep commit messages clear, following conventional commits: `feat:`, `fix:`, `refactor:`, `test:`, `docs:`.
4. Never force-push or overwrite remote branches unless explicitly instructed.
