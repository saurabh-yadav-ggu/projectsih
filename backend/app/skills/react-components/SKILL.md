# React Component Development Skill

## When to Use
Use when building or modifying React functional components, hooks, or UI views.

## Instructions
1. Use functional components with hooks (`useState`, `useEffect`, `useCallback`, `useRef`).
2. Maintain clean separation between state management hooks and presentation components.
3. Keep dark mode aesthetics consistent with the design system tokens.
4. Ensure interactive elements include appropriate accessibility labels and hover feedback.
